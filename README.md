# ⚡ QuizMania — AI-Powered Quiz for Kids & Teens

Interactive AI-generated trivia for ages 8–18. Questions come fresh from Claude every time — tailored to each player's age group, never repeating.

---

## 🚀 Deploy with GitHub + Render (Free)

### Step 1 — Push to your GitHub repo

Create a new repo on GitHub (e.g. `quizmania`) and push these files:

```
quizmania/
├── index.html      ← the full app
├── server.js       ← Express server (serves HTML + proxies Claude)
├── package.json    ← Node dependencies
└── README.md
```

```bash
git init
git add index.html server.js package.json README.md
git commit -m "Initial QuizMania"
git remote add origin https://github.com/YOUR_USERNAME/quizmania.git
git push -u origin main
```

---

### Step 2 — Create a Web Service on Render

1. Go to [render.com](https://render.com) and sign in
2. Click **"New +"** → **"Web Service"**
3. Connect your GitHub account if not already → select your `quizmania` repo
4. Fill in the settings:

| Setting | Value |
|---|---|
| **Name** | `quizmania` |
| **Runtime** | `Node` |
| **Build Command** | `npm install` |
| **Start Command** | `node server.js` |
| **Instance Type** | `Free` |

5. Click **"Create Web Service"**

---

### Step 3 — Add your Claude API key

In Render → your service → **Environment** tab → **Add Environment Variable**:

| Key | Value |
|---|---|
| `ANTHROPIC_API_KEY` | `sk-ant-api03-...` |

Render will automatically redeploy. Your live URL will be something like:
`https://quizmania.onrender.com` 🎉

---

### Step 4 — Share the URL!

Send the link to anyone. They open it, enter their name + age group, and start playing immediately. No account, no API key required on their end.

## ⚠️ Free Tier Note

Render's free tier **spins down** after 15 minutes of inactivity. The first person to visit after a quiet period will wait ~30 seconds for the server to wake up. To avoid this, upgrade to Render's Starter plan ($7/mo) or add an uptime monitoring ping (e.g. [UptimeRobot](https://uptimerobot.com) — free).

## 🎮 Features

- 12 topics + open custom topics (Harry Potter, Formula 1, Minecraft...)
- Questions generated by Claude — age-calibrated, never repeated
- Adaptive difficulty, streaks, achievements, full quiz history
- 50:50 lifeline + Ask Claude for hints
- Voice mode, dark/light mode
- Optional GitHub Gist sync per user for cross-device history
